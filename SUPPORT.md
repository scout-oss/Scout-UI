# Support Policy

Scout UI is pre-release software. The repository's issue tracker is the support
channel for reproducible bugs, accessibility problems, documentation gaps, and
focused feature proposals. Security vulnerabilities must follow `SECURITY.md`
instead.

For public API and usage guidance, start with the official documentation at
[design.scoutapp.in](https://design.scoutapp.in/).

Before opening an issue:

1. Confirm the behavior with a minimal reproduction.
2. Include package versions, framework, browser, operating system, and relevant
   accessibility settings.
3. Describe expected and actual behavior.
4. Remove private application data and credentials.

Support is best-effort until a public service-level policy is adopted. General
application debugging, private integration work, and guaranteed response times
are outside the current support commitment.
