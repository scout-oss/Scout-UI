# Proposed public component enhancements (NOT implemented — approval needed)

The v0.1 public API is frozen. Everything in the kinetic redesign lives in
`apps/docs` (demo/website level). The ideas below emerged from that work and are
proposed for a post-v0.1 minor release. Each is additive and opt-in.

| #   | Component                 | Proposal                                                                                                                                                                                                                                                                                                                                   | Compatibility                                                                                                                                                                                                                                           | Performance / a11y notes                                                                                                                                                                                                                                                                    |
| --- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1  | `StickerNavbar`           | **Bug-class fix:** desktop nav uses `justify-content: flex-end`; when links outgrow the column (real fonts, 8 items at 1024–1440px) they overflow _left, under the brand_. Use `justify-content: safe flex-end` and allow the list to wrap or collapse to the menu earlier.                                                                | CSS-only, no prop change. Visual baselines for the navbar would change — needs baseline approval.                                                                                                                                                       | Fixes overlapping hit targets (an a11y issue). The docs work around it with compact item styles in `kinetic.css`.                                                                                                                                                                           |
| P2  | Package tokens            | `--sui-font-display/body: inherit` at `:root` resolves to the UA default when a consumer's own font tokens sit in an earlier cascade layer. Document the layer-order requirement and/or default to `inherit` only on components, not `:root`.                                                                                              | Documentation now; token change is behaviour-visible → minor release.                                                                                                                                                                                   | Prevents the silent Times fallback found on the release docs.                                                                                                                                                                                                                               |
| P3  | `Sticker`                 | `draggable?: "none" \| "throw" \| "return"` — carry with velocity tilt; `throw` glides with friction inside the nearest `[data-sui-bounds]`, `return` springs home ("sticks back").                                                                                                                                                        | Additive prop, default `"none"`. Requires a client leaf (`Sticker` is server-compatible today) — ship as a separate `StickerDraggable` leaf to keep `Sticker` RSC-safe.                                                                                 | Imperative transforms, no React state per move; touch intent detection (pan-y); keyboard alternative must be specified (e.g. arrow-key nudge + Enter to "drop"). ~1.5 KB gzip.                                                                                                              |
| P4  | `StickerButton`           | `feedback?: "press" \| "squash"` — `squash` adds a spring-sampled `linear()` release overshoot.                                                                                                                                                                                                                                            | Additive, default `"press"` (current).                                                                                                                                                                                                                  | CSS-only; reduced motion falls back to current press.                                                                                                                                                                                                                                       |
| P5  | `StickerStack`            | Velocity-based release: fling distance decides next/previous instead of a fixed threshold; spring settle uses `--sui-ease-*` `linear()` curves.                                                                                                                                                                                            | Behaviour change behind `release?: "threshold" \| "velocity"` (default `"threshold"`).                                                                                                                                                                  | Already imperative; no extra listeners.                                                                                                                                                                                                                                                     |
| P6  | `StickerPeel`             | Optional underside shading + lift shadow separation tied to progress (`shading?: boolean`).                                                                                                                                                                                                                                                | Additive, default `false`.                                                                                                                                                                                                                              | Transform/opacity only; forced-colors: disabled.                                                                                                                                                                                                                                            |
| P7  | Motion tokens             | Publish `--sui-ease-slap`, `--sui-ease-lift`, `--sui-ease-settle` as `linear()` spring curves with `cubic-bezier` fallbacks via `@supports`.                                                                                                                                                                                               | Additive tokens.                                                                                                                                                                                                                                        | Zero JS. Requires token snapshot update (public API snapshot) — needs approval.                                                                                                                                                                                                             |
| P8  | `StickerTrail` / `Cursor` | Expose the `sleep-when-idle` guarantee as a documented contract and a test helper (pending-frame probe).                                                                                                                                                                                                                                   | Docs/test only.                                                                                                                                                                                                                                         | Codifies what the M17 runtime test already measures.                                                                                                                                                                                                                                        |
| P9  | `StickerTrail`            | **Collage grammar** (from the ugly.cash study): `preset: "collage"` (large art, no rotation, ~20px spacing, 1000ms), `entrance?: "stick" \| "none"`, `exit?: … \| "cut"` (hard disappear, no fade), and newest-on-top stacking for recycled pool slots. Implemented today only as the docs-level `CollageTrailLayer` on the design branch. | Additive: new preset union member, new optional `entrance`, new exit member; stacking order is a behaviour change for all presets unless gated (`stacking?: "pool" \| "newest"`, default `"pool"`). Public type snapshot + changeset needed; post-v0.1. | Stacking via incrementing `z-index` on the recycled node (one style write per spawn, no DOM moves). A `cut` exit removes the per-frame opacity write. Large art (200px) should stay raster (WebP) — 48 filtered SVGs would be too expensive to paint. Reduced motion: unchanged (disabled). |

## Implemented as opt-ins on the design branch (pending release approval)

At the user's request (round 5) three proposals moved into `@scout-ui/react`
behind new opt-in props. Defaults are unchanged, so v0.1 consumers see no
difference, but the public type surface, the tarball contents and two size
budgets changed. They ship only in a release after v0.1, with the changeset
`.changeset/opt-in-realistic-peel-badge-finish-deck.md`, and need maintainer
sign-off on the re-baselined snapshots.

| Prop                                     | Supersedes | What it does                                                                                                                                                                                                                                              |
| ---------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `StickerPeel appearance="realistic"`     | P6         | Fold-line geometry (perpendicular bisector of corner → pointer), clip-path front, reflected paper backside with crease shading, separate blurred cast shadow, spring settle, hover lift. Imperative, no React state per move. Forced colors: flap hidden. |
| `StickerBadge finish="enamel" \| "foil"` | new        | CSS-only materials: enamel pin (metal rim, gloss, pressed selected state) and holographic foil (sweep on hover). Badge stays server-compatible.                                                                                                           |
| `StickerStack appearance="deck"`         | P5 (part)  | Fanned deck of prints; the held card follows the pointer in 2D with rotation and is thrown from its release pose on commit. Buttons and keys keep the same navigation.                                                                                    |

## Explicitly not proposed

- No animation-library dependency.
- No site-wide custom cursor or smooth-scroll.
- No change to `@scout-ui/stickers` (must stay React-free). The docs-only
  printed-matter collage art (`apps/docs/public/collage`, generated by
  `tooling/docs-collage/generate.mjs`) is a candidate for a post-v0.1 "printed
  matter" family once provenance is recorded in `LICENSE-ASSETS.md`.
