# Attribution and Provenance

The Scout UI Official v0.1 pack contains original generic vector artwork created
for this repository. It contains no copied third-party artwork and no asset from
the Scout product repository.

- **Creator record:** Scout UI contributors, with Codex-assisted SVG authoring.
- **Source:** original SVG source written directly from the Scout UI design
  specifications; no reference image or image-generation service was used.
- **Artwork license:** CC0 1.0 Universal.
- **Attribution status:** not required.
- **Editable source:** each distributed SVG is also its editable vector master.
- **Checksums:** generated per asset in `assets/manifest.json` and the typed
  manifest.

The AI assistance disclosure does not replace human review. Maintainers must
confirm that submitted artwork is generic, non-infringing, visually original,
and eligible for redistribution before marking it official.
